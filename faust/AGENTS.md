# Instructions pour les agents

Avant de créer ou modifier un patch dans ce dossier, lire
[`README.md`](README.md). Il décrit le flux de travail de référence pour
générer des patches Max complets avec Faust, `faustgen~`, une interface Max et
`py2max`.

Pour les patches situés dans `max-patches/`, lire aussi
[`max-patches/PROMPT.md`](max-patches/PROMPT.md) et partir, lorsque c’est
pertinent, d’un générateur Python existant. Conserver le script générateur et
le fichier `.maxpat` produit ensemble.
